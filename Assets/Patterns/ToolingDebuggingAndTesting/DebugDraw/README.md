# Debug Draw

**Category:** Tooling, Debugging & Testing · **Site slug:** `debug-draw`

> Immediate-mode lines, shapes and labels to visualise invisible state.

## What this sample will show

There is no "without" version of this one: without it you simply can't see the state; there is no feature to build the "plain" way. WithPattern draws a component's invisible settings (ranges, cones, paths) as Gizmos.

## Where to begin

1. Read the pattern page: https://antoniucraciun.github.io/GameDevPatterns/patterns/debug-draw
2. Read [WithoutPattern](WithoutPattern/README.md) for why there is no "without" version.
3. Open [WithPattern](WithPattern/README.md) to see the pattern.
