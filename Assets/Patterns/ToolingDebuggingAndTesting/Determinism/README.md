# Determinism

**Category:** Tooling, Debugging & Testing · **Site slug:** `determinism`

> Same inputs always produce the same outputs — enabling replays, lockstep and tests.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Determinism, so you can run both and compare them.

The problem, from the page:

> You record a player's inputs to replay a bug. On playback the run diverges after ten seconds: an enemy turns slightly differently, a bullet misses, and soon the replay shows a different game.
