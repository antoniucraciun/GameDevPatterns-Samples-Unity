# Automated Playtesting

**Category:** Tooling, Debugging & Testing · **Site slug:** `automated-playtesting`

> Bots and scripted inputs that play the game to catch regressions.

## What this sample will show

There is no "without" version of this one: the alternative is a person replaying the game by hand, which a sample can't show. WithPattern is a Play Mode smoke test that loads each sample scene and fails on errors.

## Where to begin

1. Read the pattern page: https://antoniucraciun.github.io/GameDevPatterns/patterns/automated-playtesting
2. Read [WithoutPattern](WithoutPattern/README.md) for why there is no "without" version.
3. Open [WithPattern](WithPattern/README.md) to see the pattern.
