# Debug Console & Cheats: with the pattern

The same feature built with Debug Console & Cheats. The idea, from the page: Build one **console**: a text box that opens with a key (often the backtick), where typed commands run registered functions.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.
