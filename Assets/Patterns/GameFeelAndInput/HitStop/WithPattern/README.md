# Hit Stop: with the pattern

The same feature built with Hit Stop. The idea, from the page: On impact, **stop time briefly**: typically 40–150 ms, roughly 3–9 frames at 60 FPS. The frozen frame gives the eye a moment to register the contact, the pose and the effect, and resuming afterwards makes the motion snap forward.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.
