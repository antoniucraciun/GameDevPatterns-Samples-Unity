# Coyote Time

**Category:** Game Feel & Input · **Site slug:** `coyote-time`

> Allow jumping for a few frames after walking off a ledge.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Coyote Time, so you can run both and compare them.

The problem, from the page:

> The player runs toward a gap and presses Jump at what *looks* like the edge. On the exact frame of the press, the character's collider has already left the platform, so the ground check fails and the character falls.
