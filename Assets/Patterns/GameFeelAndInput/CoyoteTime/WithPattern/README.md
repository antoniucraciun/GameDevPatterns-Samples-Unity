# Coyote Time: with the pattern

The same feature built with Coyote Time. The idea, from the page: Record **when the character was last grounded**. Allow a jump as long as that moment was within a short grace period, typically 0.08–0.15 s.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
