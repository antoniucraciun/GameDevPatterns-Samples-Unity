# Input Abstraction

**Category:** Game Feel & Input · **Site slug:** `input-abstraction`

> Map physical buttons to game actions so code never reads raw keys.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Input Abstraction, so you can run both and compare them.

The problem, from the page:

> The player controller checks whether Space was pressed. Then gamepad support is needed, so the check grows into `Space || JoystickButton0`.
