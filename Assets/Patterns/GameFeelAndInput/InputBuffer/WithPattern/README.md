# Input Buffer: with the pattern

The same feature built with Input Buffer. The idea, from the page: When an action is pressed but cannot happen yet, **remember the press with a timestamp** instead of discarding it. Each frame, check whether the action has become possible.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
