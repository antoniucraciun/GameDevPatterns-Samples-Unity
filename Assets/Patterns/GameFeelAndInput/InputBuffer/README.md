# Input Buffer

**Category:** Game Feel & Input · **Site slug:** `input-buffer`

> Remember inputs briefly so presses slightly too early still count.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Input Buffer, so you can run both and compare them.

The problem, from the page:

> The player presses Jump a few frames before landing. The character is still airborne, so the jump is rejected.
