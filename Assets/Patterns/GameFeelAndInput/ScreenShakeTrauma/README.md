# Screen Shake (Trauma)

**Category:** Game Feel & Input · **Site slug:** `screen-shake`

> Drive camera shake from a decaying trauma value and smooth noise.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Screen Shake (Trauma), so you can run both and compare them.

The problem, from the page:

> The typical first screen shake offsets the camera by a random amount every frame for half a second. It looks like a broken video signal rather than an impact.
