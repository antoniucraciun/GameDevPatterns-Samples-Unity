# Client-Side Prediction: with the pattern

The same feature built with Client-Side Prediction. The idea, from the page: The client **runs the same movement code as the server**, on its own inputs, right away. It shows the predicted result while the input is still travelling to the server.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
