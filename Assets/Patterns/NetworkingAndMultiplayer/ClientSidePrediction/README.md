# Client-Side Prediction

**Category:** Networking & Multiplayer · **Site slug:** `client-side-prediction`

> Apply local input immediately instead of waiting for the server round trip.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Client-Side Prediction, so you can run both and compare them.

The problem, from the page:

> With an authoritative server, the client sends "move forward" and waits for the server's updated position. At 100 ms round-trip time, every key press feels a tenth of a second late.
