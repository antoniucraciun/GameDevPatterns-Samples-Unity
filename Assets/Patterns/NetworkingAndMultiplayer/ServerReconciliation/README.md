# Server Reconciliation

**Category:** Networking & Multiplayer · **Site slug:** `server-reconciliation`

> Rewind to the server state and replay unacknowledged inputs to fix mispredictions.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Server Reconciliation, so you can run both and compare them.

The problem, from the page:

> With Client-Side Prediction, the client moves the player immediately. The server's state updates are always one round trip *behind* the client.
