# Lag Compensation

**Category:** Networking & Multiplayer · **Site slug:** `lag-compensation`

> The server rewinds hitboxes to what the shooter saw when validating hits.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Lag Compensation, so you can run both and compare them.

The problem, from the page:

> With Entity Interpolation, you see other players about 100 ms in the past, plus your own latency. You aim perfectly at an enemy's head and click.
