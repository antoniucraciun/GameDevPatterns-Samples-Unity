# Authoritative Server

**Category:** Networking & Multiplayer · **Site slug:** `authoritative-server`

> The server owns the truth; clients send inputs and receive state.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Authoritative Server, so you can run both and compare them.

The problem, from the page:

> In the first multiplayer prototype, each client simulates its own player and tells the others "I'm at (10, 2, 5), I have 500 health, I hit player 3 for 9,999 damage". It works until someone edits memory or packets: they teleport, become immortal and kill everyone instantly.
