# Entity Interpolation

**Category:** Networking & Multiplayer · **Site slug:** `entity-interpolation`

> Render remote entities slightly in the past, smoothing between received snapshots.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Entity Interpolation, so you can run both and compare them.

The problem, from the page:

> The server sends the positions of other players 20 times a second, but the client renders at 60–144 FPS. Applying each update as it arrives makes remote players teleport in 50 ms jumps.
