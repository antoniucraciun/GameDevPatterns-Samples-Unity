# Entity Interpolation: with the pattern

The same feature built with Entity Interpolation. The idea, from the page: Do not show remote entities where they are *now*. Show where they were a short, fixed time **in the past**, a moment for which you already have snapshots on *both sides*.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
