# Rollback Netcode

**Category:** Networking & Multiplayer · **Site slug:** `rollback-netcode`

> Predict remote inputs, then roll back and resimulate when the real ones arrive.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Rollback Netcode, so you can run both and compare them.

The problem, from the page:

> A fighting game needs frame-perfect timing: a 3-frame window to punish, a 1-frame link. With lockstep, each input waits for the opponent's input of the same frame.
