# Deterministic Lockstep

**Category:** Networking & Multiplayer · **Site slug:** `deterministic-lockstep`

> Exchange only inputs; every peer runs the same deterministic simulation.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Deterministic Lockstep, so you can run both and compare them.

The problem, from the page:

> An RTS match has 8 players and 2,000 units. Replicating 2,000 units' positions, health and orders with snapshots needs far too much bandwidth, even with delta compression.
