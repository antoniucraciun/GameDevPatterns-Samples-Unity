# Strategy

**Category:** Behavioral & Communication · **Site slug:** `strategy`

> Swap an algorithm (movement, targeting, damage formula) at runtime behind one interface.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Strategy, so you can run both and compare them.

The problem, from the page:

> A tower-defence turret picks targets with a `switch` on an enum: nearest, first along the path, strongest, weakest. Every new targeting mode means editing the turret.
