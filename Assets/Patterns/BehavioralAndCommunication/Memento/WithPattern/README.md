# Memento: with the pattern

The same feature built with Memento. The idea, from the page: The object whose state is saved (the **originator**) can produce a **memento**: an opaque snapshot of its own state. It can later restore itself from that memento.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
