# Memento

**Category:** Behavioral & Communication · **Site slug:** `memento`

> Capture and restore an object's state without exposing its internals.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Memento, so you can run both and compare them.

The problem, from the page:

> A puzzle game needs "restart room", a strategy game needs "undo last turn", and a level editor needs undo for a complex prop with twenty settings. Writing a hand-crafted reverse operation for every possible change is tedious and easy to get wrong.
