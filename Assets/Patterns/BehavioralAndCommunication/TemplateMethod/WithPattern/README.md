# Template Method: with the pattern

The same feature built with Template Method. The idea, from the page: Put the **fixed sequence of steps** in one method of the base class: the **template method**. Make it non-overridable.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
