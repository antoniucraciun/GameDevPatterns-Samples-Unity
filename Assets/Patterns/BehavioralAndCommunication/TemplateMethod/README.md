# Template Method

**Category:** Behavioral & Communication · **Site slug:** `template-method`

> A base class fixes the steps of an algorithm and lets subclasses fill some in.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Template Method, so you can run both and compare them.

The problem, from the page:

> In a turn-based tactics game, every unit's turn follows the same rules: tick status effects, skip the turn if stunned, regenerate action points, choose an action, perform it, trigger end-of-turn effects, and tell the turn manager it is done. The knight, the archer and the AI-controlled goblin differ only in *how they choose and perform* their action.
