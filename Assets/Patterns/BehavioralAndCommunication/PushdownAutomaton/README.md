# Pushdown Automaton

**Category:** Behavioral & Communication · **Site slug:** `pushdown-automaton`

> A state machine with a stack, so states can be pushed and later resumed.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Pushdown Automaton, so you can run both and compare them.

The problem, from the page:

> A character is *Running* when it gets stunned. When the stun ends, which state should it return to?
