# Hierarchical State Machine

**Category:** Behavioral & Communication · **Site slug:** `hierarchical-state-machine`

> Nest states inside super-states to share transitions and behaviour.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Hierarchical State Machine, so you can run both and compare them.

The problem, from the page:

> A character controller built as a flat state machine has *Idle*, *Running*, *Crouching*, *Jumping* and *Falling*. Idle, Running and Crouching all need the same rules: jump when Jump is pressed, fall when the ground disappears, take hits.
