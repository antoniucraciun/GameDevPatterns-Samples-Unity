# Command: with the pattern

The same feature built with Command. The idea, from the page: Wrap each action in a **command object** with an `Execute` method, and optionally `Undo`. Input code (or AI, or a network packet) creates commands.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
