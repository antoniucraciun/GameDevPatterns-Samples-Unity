# Command

**Category:** Behavioral & Communication · **Site slug:** `command`

> Turn a request into an object you can queue, replay, undo or send over a network.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Command, so you can run both and compare them.

The problem, from the page:

> Input handling often calls gameplay methods directly: `if (jumpPressed) player.Jump();`. That works until you need rebindable controls, AI that drives the same character, undo in a level editor, a replay system, or sending player actions to a server.
