# Visitor

**Category:** Behavioral & Communication · **Site slug:** `visitor`

> Add operations over a fixed object hierarchy without modifying its classes.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Visitor, so you can run both and compare them.

The problem, from the page:

> A level editor has a handful of element types: `Wall`, `Door`, `SpawnPoint`, `Trigger`, `Light`. Over time, more and more operations are needed on them: validate the level, compute a performance budget, export to the runtime format, draw editor gizmos, generate a minimap, count objectives.
