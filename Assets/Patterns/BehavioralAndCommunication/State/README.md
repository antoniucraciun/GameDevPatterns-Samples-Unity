# State

**Category:** Behavioral & Communication · **Site slug:** `state`

> Let an object change its behaviour when its internal state changes.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with State, so you can run both and compare them.

The problem, from the page:

> A player controller starts with a few booleans: `isJumping`, `isCrouching`, `isAttacking`, `isDashing`. Each new mechanic adds another flag and more `if` checks.
