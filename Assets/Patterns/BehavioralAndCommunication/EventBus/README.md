# Event Bus

**Category:** Behavioral & Communication · **Site slug:** `event-bus`

> A central channel where any system can publish or subscribe to typed events.

## What this sample will show

The problem, from the page:

> Observer works when the listener can reach the subject: the health bar holds a reference to the player. Many reactions have no such link.
