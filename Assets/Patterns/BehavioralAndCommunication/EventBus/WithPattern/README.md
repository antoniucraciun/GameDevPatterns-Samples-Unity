# Event Bus: with the pattern

The same feature built with Event Bus. The idea, from the page: Put a **bus** in the middle. Publishers announce typed events to the bus, and subscribers register with the bus for event types they care about.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
