# Mediator

**Category:** Behavioral & Communication · **Site slug:** `mediator`

> Route interactions through one object so participants do not reference each other.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Mediator, so you can run both and compare them.

The problem, from the page:

> A puzzle room has three pressure plates, two levers, a door, four lights and a timer. The door opens when all plates are pressed and the levers are in the right positions.
