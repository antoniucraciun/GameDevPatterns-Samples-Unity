# Bytecode

**Category:** Behavioral & Communication · **Site slug:** `bytecode`

> Encode behaviour as instructions for a small virtual machine, so it can be data.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Bytecode, so you can run both and compare them.

The problem, from the page:

> A spell-crafting game lets players and modders define new spells: "deal 10 damage to the target, heal yourself for half of that, and if your health is below 30, play the panic sound". The spells must be data, so they can be downloaded, shared and modded, but they need *logic*: arithmetic, conditions, calls into the game.
