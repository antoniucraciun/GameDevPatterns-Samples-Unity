# Bytecode: with the pattern

The same feature built with Bytecode. The idea, from the page: Define a tiny **virtual machine** with a fixed set of **instructions**, and represent behaviour as a flat **array of those instructions**: bytecode.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
