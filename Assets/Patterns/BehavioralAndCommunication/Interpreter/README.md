# Interpreter

**Category:** Behavioral & Communication · **Site slug:** `interpreter`

> Evaluate a small language or expression tree (formulas, conditions, dialogue logic).

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Interpreter, so you can run both and compare them.

The problem, from the page:

> Designers want to tune formulas without programmers: damage is `base * (1 + strength / 100) - armor * 0.5`, XP for a level is `100 * level ^ 1.5`, a dialogue choice appears when `gold >= 50 and reputation > 10`. Hard-coding each formula in code means a code change and recompile for every balance tweak.
