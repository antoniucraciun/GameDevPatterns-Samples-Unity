# Update Method

**Category:** Game Loop & Timing · **Site slug:** `update-method`

> Let every object simulate one frame of its own behaviour when asked.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Update Method, so you can run both and compare them.

The problem, from the page:

> A world holds dozens of independent things: a patrolling guard, a spinning pickup, a door that slowly closes. Hard-coding all of their behaviour into one giant loop body does not scale, and adding a new kind of object would mean editing that loop.
