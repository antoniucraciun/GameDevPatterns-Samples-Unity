# Time Scale

**Category:** Game Loop & Timing · **Site slug:** `time-scale`

> Route all simulation time through a scalable clock for pause, slow-mo and fast-forward.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Time Scale, so you can run both and compare them.

The problem, from the page:

> The pause menu sets the global time scale to 0 (`Time.timeScale`, `Engine.time_scale`, global time dilation). A slow-motion finisher sets it to 0.2, then back to 1 when it ends, which unpauses the game if the player paused during the finisher.
