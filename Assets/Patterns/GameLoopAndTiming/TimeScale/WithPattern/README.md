# Time Scale: with the pattern

The same feature built with Time Scale. The idea, from the page: Treat time scaling as **requests that combine**, not as a value anyone can overwrite, and decide for every system **which clock it runs on**.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
