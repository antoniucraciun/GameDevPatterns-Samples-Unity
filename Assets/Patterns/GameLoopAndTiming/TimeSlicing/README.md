# Time Slicing

**Category:** Game Loop & Timing · **Site slug:** `time-slicing`

> Spread expensive work over several frames to stay within the frame budget.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Time Slicing, so you can run both and compare them.

The problem, from the page:

> At 60 FPS, a frame has 16.6 ms for *everything*. Regenerating the navmesh for a destroyed building takes 40 ms.
