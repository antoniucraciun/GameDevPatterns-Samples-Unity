# Game Loop

**Category:** Game Loop & Timing · **Site slug:** `game-loop`

> Decouple the progression of game time from user input and processor speed.

## What this sample will show

There is no "without" version of this one: Unity owns the game loop (the PlayerLoop), so there is no plain Unity version without it. The sample only shows how to add your own step to the loop Unity already runs.

## Where to begin

1. Read the pattern page: https://antoniucraciun.github.io/GameDevPatterns/patterns/game-loop
