# Fixed Timestep: with the pattern

The same feature built with Fixed Timestep. The idea, from the page: Choose a constant step, for example 1/50 s. Keep an **accumulator** of real time not yet simulated.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
