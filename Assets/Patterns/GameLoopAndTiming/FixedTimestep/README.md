# Fixed Timestep

**Category:** Game Loop & Timing · **Site slug:** `fixed-timestep`

> Advance the simulation in constant increments for stable, reproducible physics.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Fixed Timestep, so you can run both and compare them.

The problem, from the page:

> When the simulation advances by a variable `deltaTime`, results depend on the frame rate. A jump reaches a different height at 30 FPS than at 144 FPS.
