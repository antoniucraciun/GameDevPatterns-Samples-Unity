# Blackboard: with the pattern

The same feature built with Blackboard. The idea, from the page: Give each agent a **blackboard**: a dictionary of facts, keyed by name or by typed key, that any component can read and write.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
