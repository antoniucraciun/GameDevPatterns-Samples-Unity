# Blackboard

**Category:** AI & Decision Making · **Site slug:** `blackboard`

> A shared key–value memory that decision-making components read and write.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Blackboard, so you can run both and compare them.

The problem, from the page:

> A guard's behavior tree has a "can see player?" condition, a "move to last known position" action and an "investigate noise" action. They all need the same facts: who the target is, where it was last seen, where the noise came from.
