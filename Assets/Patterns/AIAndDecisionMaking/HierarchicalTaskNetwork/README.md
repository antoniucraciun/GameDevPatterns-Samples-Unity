# Hierarchical Task Network

**Category:** AI & Decision Making · **Site slug:** `htn-planning`

> Plan by decomposing high-level tasks into primitive ones using authored methods.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Hierarchical Task Network, so you can run both and compare them.

The problem, from the page:

> GOAP finds clever plans, but designers lose control. The planner may pick an odd sequence because the costs happen to favour it, and planning slows down as facts and actions grow.
