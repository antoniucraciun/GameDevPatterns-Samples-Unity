# Utility AI: with the pattern

The same feature built with Utility AI. The idea, from the page: Give every candidate action a **score** between 0 and 1, computed from the current situation, and pick the highest (or pick randomly among the top few).

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
