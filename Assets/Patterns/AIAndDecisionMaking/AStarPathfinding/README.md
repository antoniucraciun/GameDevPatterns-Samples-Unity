**Category:** AI & Decision Making · **Site slug:** `a-star`

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with A* Pathfinding, so you can run both and compare them.

The problem, from the page:

> An enemy needs to reach the player through a maze of walls. Moving straight toward the target gets stuck on the first obstacle.
