# Flow Field

**Category:** AI & Decision Making · **Site slug:** `flow-field`

> Precompute a direction per cell so thousands of units can share one path.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Flow Field, so you can run both and compare them.

The problem, from the page:

> An RTS player selects 800 units and clicks across the map. Running A* 800 times is expensive, and every unit gets the same narrow optimal line, so they queue single file through the same tiles.
