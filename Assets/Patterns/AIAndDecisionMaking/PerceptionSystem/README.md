# Perception System

**Category:** AI & Decision Making · **Site slug:** `perception-system`

> Centralised sight, hearing and memory so agents react to stimuli consistently.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Perception System, so you can run both and compare them.

The problem, from the page:

> Each enemy script decides for itself whether it can see the player: one uses a distance check, another a raycast, a third forgets the field of view. Gunshots alert enemies through the gun searching the whole scene for enemies.
