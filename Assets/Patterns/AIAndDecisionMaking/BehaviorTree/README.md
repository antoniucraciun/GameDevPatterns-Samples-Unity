# Behavior Tree

**Category:** AI & Decision Making · **Site slug:** `behavior-tree`

> Compose agent behaviour from a tree of reusable tasks, selectors and sequences.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Behavior Tree, so you can run both and compare them.

The problem, from the page:

> A guard should patrol, investigate noises, chase the player when seen, attack in range, and flee at low health. As a state machine, every state needs explicit transitions to most other states.
