# Behavior Tree: with the pattern

The same feature built with Behavior Tree. The idea, from the page: Arrange behaviour as a **tree** that is evaluated from the root every tick. Each node returns **Success**, **Failure** or **Running**.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.
