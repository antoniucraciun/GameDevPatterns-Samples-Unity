# Steering Behaviors: with the pattern

The same feature built with Steering Behaviors. The idea, from the page: Model each agent as a simple **vehicle**: a position, a velocity, a maximum speed and a maximum steering force. Each frame, behaviours each compute a **desired velocity**.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
