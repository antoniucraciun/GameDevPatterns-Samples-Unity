# Goal-Oriented Action Planning

**Category:** AI & Decision Making · **Site slug:** `goap`

> Agents search for a sequence of actions whose effects satisfy a goal.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Goal-Oriented Action Planning, so you can run both and compare them.

The problem, from the page:

> A soldier AI should "kill the enemy". Depending on the situation, that means *shoot*, or *reload, then shoot*, or *pick up ammo, reload, move into range, shoot*, or *pick up a knife and charge*.
