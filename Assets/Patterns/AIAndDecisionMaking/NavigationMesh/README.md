# Navigation Mesh

**Category:** AI & Decision Making · **Site slug:** `navigation-mesh`

> Represent walkable space as convex polygons for efficient pathfinding.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Navigation Mesh, so you can run both and compare them.

The problem, from the page:

> A grid works for tile-based games, but a 3D level with slopes, stairs, bridges and irregular buildings fits a grid badly. Fine cells are needed to follow walls, which means millions of nodes and slow searches.
