# Influence Map: with the pattern

The same feature built with Influence Map. The idea, from the page: Keep **grids of numbers over the map**. Each unit **stamps** its influence onto the grid, strongest at its position and falling off with distance.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
