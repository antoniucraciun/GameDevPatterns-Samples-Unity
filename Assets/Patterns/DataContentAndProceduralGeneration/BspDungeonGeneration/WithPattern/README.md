# BSP Dungeon Generation: with the pattern

The same feature built with BSP Dungeon Generation. The idea, from the page: Use **binary space partitioning (BSP)**: recursively split the map into smaller rectangles, put one room in each final rectangle, and connect rooms following the split tree.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
