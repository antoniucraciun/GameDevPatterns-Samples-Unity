# BSP Dungeon Generation

**Category:** Data, Content & Procedural Generation · **Site slug:** `bsp-dungeon`

> Recursively split space into rooms and connect them with corridors.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with BSP Dungeon Generation, so you can run both and compare them.

The problem, from the page:

> A roguelike needs a new dungeon every run: rectangular rooms that do not overlap, spread across the map, all reachable, with corridors between them. Placing rooms at random positions leads to overlaps, clusters and empty areas, and connecting arbitrary rooms produces corridors that cross everywhere.
