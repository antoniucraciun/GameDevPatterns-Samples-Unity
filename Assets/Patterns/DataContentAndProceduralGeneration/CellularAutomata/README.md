# Cellular Automata

**Category:** Data, Content & Procedural Generation · **Site slug:** `cellular-automata`

> Iterate simple neighbour rules over a grid to grow caves and organic shapes.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Cellular Automata, so you can run both and compare them.

The problem, from the page:

> A roguelike or mining game needs caves: organic, irregular, connected spaces. Random noise produces speckled static rather than chambers.
