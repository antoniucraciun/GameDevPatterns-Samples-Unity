# Cellular Automata: with the pattern

The same feature built with Cellular Automata. The idea, from the page: Start with a random grid, then repeatedly apply a **local rule** to every cell based on its neighbours, all cells at once. Over a few iterations, noise **smooths into blobs** of wall and open space.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
