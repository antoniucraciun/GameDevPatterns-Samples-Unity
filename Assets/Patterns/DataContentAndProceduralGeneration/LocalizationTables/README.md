# Localization Tables

**Category:** Data, Content & Procedural Generation · **Site slug:** `localization-tables`

> All player-facing text lives in keyed tables per locale.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Localization Tables, so you can run both and compare them.

The problem, from the page:

> Text is written directly in code and scenes: `label.text = "You found " + count + " coins!"`. When the game is translated, someone must hunt down every string in scripts and scenes, and some are missed.
