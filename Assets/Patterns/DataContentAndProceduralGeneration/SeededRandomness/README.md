# Seeded Randomness

**Category:** Data, Content & Procedural Generation · **Site slug:** `seeded-randomness`

> Use explicit, seeded RNG streams so generation and replays are reproducible.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Seeded Randomness, so you can run both and compare them.

The problem, from the page:

> A player shares the seed of an amazing procedurally generated world, but their friend gets a different world from the same seed. A replay diverges because a particle effect consumed a random number.
