# Wave Function Collapse: with the pattern

The same feature built with Wave Function Collapse. The idea, from the page: Describe only **local rules**, meaning which tiles may sit next to which in each direction, and let a constraint solver fill the grid. (The name borrows loosely from quantum physics.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
