# Data-Driven Design

**Category:** Data, Content & Procedural Generation · **Site slug:** `data-driven-design`

> Move tuning and content out of code into data designers can edit.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Data-Driven Design, so you can run both and compare them.

The problem, from the page:

> Jump height is a constant in `PlayerController.cs`. Enemy health lives in the enemy class.
