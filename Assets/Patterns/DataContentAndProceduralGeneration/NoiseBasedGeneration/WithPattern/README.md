# Noise-Based Generation: with the pattern

The same feature built with Noise-Based Generation. The idea, from the page: Use **coherent noise**: a function `noise(x, y)` that returns similar values for nearby inputs and varies smoothly. Perlin and Simplex noise are the standard choices.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
