# Noise-Based Generation

**Category:** Data, Content & Procedural Generation · **Site slug:** `noise-generation`

> Layer coherent noise (Perlin, Simplex) to generate terrain and variation.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Noise-Based Generation, so you can run both and compare them.

The problem, from the page:

> Generating terrain with an independent random value per tile gives static: every tile unrelated to its neighbours, with no hills, valleys or coastlines. Hand-authoring a large world is not feasible.
