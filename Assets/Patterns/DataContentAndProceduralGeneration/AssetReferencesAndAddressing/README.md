# Asset References & Addressing

**Category:** Data, Content & Procedural Generation · **Site slug:** `asset-reference`

> Refer to assets by stable keys and load them on demand instead of hard links.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Asset References & Addressing, so you can run both and compare them.

The problem, from the page:

> A level-select menu has direct references to all 40 level backgrounds. Because the engine loads everything a loaded object hard-references, all 40 textures (800 MB) load the moment the menu opens.
