# Builder

**Category:** Architecture & Structure · **Site slug:** `builder`

> Assemble complex objects step by step with a readable, validated API.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Builder, so you can run both and compare them.

The problem, from the page:

> A loot system generates weapons: a base type, a rarity, two to five random affixes, a level that scales stats, an optional unique effect, and a generated name ("Blazing Longsword of the Fox"). A constructor with nine parameters is unreadable and easy to call wrongly.
