# Proxy

**Category:** Architecture & Structure · **Site slug:** `proxy`

> Stand in for another object behind the same interface to defer, guard or forward access (lazy-loaded assets).

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Proxy, so you can run both and compare them.

The problem, from the page:

> A town in an RPG has forty NPCs, each with a voice bank of a few hundred recorded lines. Loading every bank with the town costs over a gigabyte of memory and a long loading screen, and the player talks to perhaps five of them.
