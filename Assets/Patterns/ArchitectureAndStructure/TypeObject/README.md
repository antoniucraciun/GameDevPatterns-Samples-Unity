# Type Object

**Category:** Architecture & Structure · **Site slug:** `type-object`

> Define new "kinds" of things as data instances rather than as subclasses.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Type Object, so you can run both and compare them.

The problem, from the page:

> The game has goblins, orcs and trolls, so you write `Goblin : Enemy`, `Orc : Enemy` and `Troll : Enemy`. Then design wants 60 enemy kinds, plus variants: "Goblin Archer", "Elite Orc", "Frost Troll".
