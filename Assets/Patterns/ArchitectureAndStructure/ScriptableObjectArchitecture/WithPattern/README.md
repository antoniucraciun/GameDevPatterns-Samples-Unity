# ScriptableObject Architecture: with the pattern

The same feature built with ScriptableObject Architecture. The idea, from the page: Use **data assets** as the shared meeting point: ScriptableObjects in Unity, `Resource`s in Godot, Data Assets in Unreal. An asset exists outside any scene, so any scene object can reference it from the editor.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
