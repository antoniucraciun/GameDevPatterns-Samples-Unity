# Feature Flags

**Category:** Architecture & Structure · **Site slug:** `feature-flags`

> Toggle features at build or run time without branching the codebase.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Feature Flags, so you can run both and compare them.

The problem, from the page:

> A new crafting system is half finished, but the main branch must ship a patch next week. Keeping crafting on a long-lived feature branch leads to painful merges.
