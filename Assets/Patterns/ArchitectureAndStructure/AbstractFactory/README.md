# Abstract Factory

**Category:** Architecture & Structure · **Site slug:** `abstract-factory`

> Create families of objects that must match (per platform, UI skin or biome) through one interface.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Abstract Factory, so you can run both and compare them.

The problem, from the page:

> The game ships as a desktop build and as a trade-show kiosk build, and the team is preparing a console port. Three systems differ between them: where saves go, where achievements are recorded, and which button names the prompts show ("[Space] Jump" or "(A) Jump").
