# Facade

**Category:** Architecture & Structure · **Site slug:** `facade`

> Hide a complicated subsystem (audio, save, analytics) behind one simple interface.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Facade, so you can run both and compare them.

The problem, from the page:

> Playing a sound "properly" involves: picking a pooled audio player, routing it to the right mixer group, randomising pitch, choosing one of several clip variants, setting 2D or 3D spatial settings, respecting the player's volume settings, ducking music during dialogue, and returning the source to the pool afterwards. Every gameplay script that wants a sound repeats some of these steps and gets others wrong.
