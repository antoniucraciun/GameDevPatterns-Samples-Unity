# Service Locator

**Category:** Architecture & Structure · **Site slug:** `service-locator`

> Provide a global access point to a service without coupling callers to its concrete type.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Service Locator, so you can run both and compare them.

The problem, from the page:

> Audio, analytics, save data and input are needed from all over the codebase. Passing them through every constructor is tedious.
