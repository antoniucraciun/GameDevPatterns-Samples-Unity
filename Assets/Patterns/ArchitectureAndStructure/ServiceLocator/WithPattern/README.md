# Service Locator: with the pattern

The same feature built with Service Locator. The idea, from the page: Callers depend on an **interface** (`IAudioService`). A central **locator** maps interfaces to the instances currently providing them.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
