# Subclass Sandbox

**Category:** Architecture & Structure · **Site slug:** `subclass-sandbox`

> A base class offers a set of safe operations that subclasses compose into behaviour.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Subclass Sandbox, so you can run both and compare them.

The problem, from the page:

> A superhero game has dozens of powers: Sky Launch, Ground Slam, Lightning Arc, Phase Dash. Each is a subclass, and each one reaches into whatever systems it needs: it finds the audio manager, spawns particles its own way, applies physics forces directly, queries enemies with its own overlap code.
