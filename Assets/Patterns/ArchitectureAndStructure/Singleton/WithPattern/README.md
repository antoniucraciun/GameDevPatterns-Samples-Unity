# Singleton: with the pattern

The same feature built with Singleton. The idea, from the page: The class controls its own instantiation and exposes the single instance through a static property. That gives two guarantees: **one instance**, and **global access**.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.
