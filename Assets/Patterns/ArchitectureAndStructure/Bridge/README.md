# Bridge

**Category:** Architecture & Structure · **Site slug:** `bridge`

> Split two dimensions that vary independently into two hierarchies (weapons × delivery mechanisms).

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Bridge, so you can run both and compare them.

The problem, from the page:

> A spell system has four **deliveries** (beam, nova, projectile, cone) and four **elements** (fire, force, frost, poison). Designers want every combination, so the first version has a class per pair: `FireBeam`, `FireNova`, `ForceBeam`, `FrostCone`… Sixteen classes, and every new element adds four more.
