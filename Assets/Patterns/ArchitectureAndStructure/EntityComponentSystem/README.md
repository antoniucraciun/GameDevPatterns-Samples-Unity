# Entity Component System

**Category:** Architecture & Structure · **Site slug:** `entity-component-system`

> Entities are IDs, components are plain data, systems hold all the logic.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Entity Component System, so you can run both and compare them.

The problem, from the page:

> The Component pattern with engine objects (GameObjects, nodes, actors) works well for hundreds of objects, and struggles with tens of thousands. Each object is a heap object with its own transform.
