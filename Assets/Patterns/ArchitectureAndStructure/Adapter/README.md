# Adapter

**Category:** Architecture & Structure · **Site slug:** `adapter`

> Wrap a third-party or platform API so the game depends only on your own interface.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Adapter, so you can run both and compare them.

The problem, from the page:

> The game ships on Steam, PlayStation, Xbox and mobile. Each platform has its own achievements API with different method names, threading rules, ID formats and error handling.
