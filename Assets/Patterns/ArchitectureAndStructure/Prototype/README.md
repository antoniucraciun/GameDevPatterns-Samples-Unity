## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Prototype, so you can run both and compare them.

The problem, from the page:

> A spawner needs to create goblins, but a goblin is not just a class. It is a specific combination of mesh, materials, colliders, components and tuned values, assembled by a designer.
