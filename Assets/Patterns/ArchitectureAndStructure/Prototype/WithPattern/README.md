# Prototype: with the pattern

The same feature built with Prototype. The idea, from the page: Create new objects by **copying an existing, fully configured one**: the **prototype**. The code that creates the copy does not need to know what the object contains.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
