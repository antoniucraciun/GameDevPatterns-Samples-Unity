# Decorator

**Category:** Architecture & Structure · **Site slug:** `decorator`

> Stack behaviour on an object at runtime by wrapping it (weapon mods, logging).

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Decorator, so you can run both and compare them.

The problem, from the page:

> A roguelike gun can pick up modifications during a run: explosive rounds, double shot, ricochet, piercing, fire damage. Any combination is possible.
