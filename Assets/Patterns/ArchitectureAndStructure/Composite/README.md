# Composite

**Category:** Architecture & Structure · **Site slug:** `composite`

> Treat a tree of objects and a single object uniformly (scene graphs, UI, BT nodes).

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Composite, so you can run both and compare them.

The problem, from the page:

> In an RTS, the player can command a single unit, a squad of six, a platoon of three squads, or an entire army. "Move to here", "attack that", "how many units?", "what is the total health?" make sense for all of them.
