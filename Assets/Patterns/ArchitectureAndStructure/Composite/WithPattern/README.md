# Composite: with the pattern

The same feature built with Composite. The idea, from the page: Make **individual objects** (leaves) and **groups** (composites) implement **the same interface**. A composite holds children of that interface, and implements each operation by delegating to them, often combining the results.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.
