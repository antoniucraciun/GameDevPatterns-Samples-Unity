# Component

**Category:** Architecture & Structure · **Site slug:** `component`

> Build entities from small, independent pieces of behaviour instead of deep inheritance.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Component, so you can run both and compare them.

The problem, from the page:

> Inheritance hierarchies for game objects collapse under real requirements. You start with `Enemy → FlyingEnemy` and `Enemy → ShootingEnemy`.
