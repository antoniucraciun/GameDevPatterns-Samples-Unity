# Dependency Injection: with the pattern

The same feature built with Dependency Injection. The idea, from the page: An object **declares** its dependencies, usually as constructor parameters, and **someone else provides them**. The object never reaches out to a global.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.
