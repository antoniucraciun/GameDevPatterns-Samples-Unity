# Dirty Flag

**Category:** Performance & Memory · **Site slug:** `dirty-flag`

> Defer expensive recalculation until a result is actually needed.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Dirty Flag, so you can run both and compare them.

The problem, from the page:

> A character's final stats depend on base values, equipment, buffs and talents. Recomputing them every frame wastes work, because they change only a few times a minute.
