# Dirty Flag: with the pattern

The same feature built with Dirty Flag. The idea, from the page: Store the derived value in a cache, together with a boolean **dirty flag**. Whenever an input changes, set the flag; do not recompute.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
