# Level of Detail

**Category:** Performance & Memory · **Site slug:** `level-of-detail`

> Use cheaper meshes, logic or update rates for things far from the player.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Level of Detail, so you can run both and compare them.

The problem, from the page:

> A character model has 40,000 triangles, a full skeleton with facial bones, cloth simulation, an AI that replans every frame, and footstep sounds. Up close, all of that detail matters.
