# Job System

**Category:** Performance & Memory · **Site slug:** `job-system`

> Split work into small independent jobs that run in parallel across cores.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Job System, so you can run both and compare them.

The problem, from the page:

> Modern CPUs have 6–16 cores, but gameplay code runs on one: the main thread. Updating 10,000 boids, sampling noise for terrain, or raycasting for 500 agents uses one core at 100% while the others idle, and the frame takes too long.
