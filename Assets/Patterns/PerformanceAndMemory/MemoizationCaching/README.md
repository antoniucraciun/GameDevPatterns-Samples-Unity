# Memoization / Caching

**Category:** Performance & Memory · **Site slug:** `memoization`

> Store the results of pure, expensive computations and reuse them.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Memoization / Caching, so you can run both and compare them.

The problem, from the page:

> The same expensive question is asked again and again with the same inputs. The pathfinder computes the route from the barracks to the gold mine every time a worker is sent, 200 times per game, and it is the same route each time.
