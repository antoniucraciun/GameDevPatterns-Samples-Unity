# Spatial Partition: with the pattern

The same feature built with Spatial Partition. The idea, from the page: Store objects in a data structure organised by **location**. A query then visits only the region of space it cares about and its contents.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.

Status: not implemented yet.
