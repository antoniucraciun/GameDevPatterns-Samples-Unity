# Flyweight

**Category:** Performance & Memory · **Site slug:** `flyweight`

> Share the heavy, unchanging data between many instances.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Flyweight, so you can run both and compare them.

The problem, from the page:

> A forest has 10,000 trees. Each one has a position, rotation, scale and tint, plus a mesh, materials, bark sound set, burn time and wood yield.
