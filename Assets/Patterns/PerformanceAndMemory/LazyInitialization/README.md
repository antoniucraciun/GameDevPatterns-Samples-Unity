# Lazy Initialization

**Category:** Performance & Memory · **Site slug:** `lazy-initialization`

> Create expensive resources on first use instead of up front.

## What this sample will show

There is no "without" version of this one: the "without" version is the same code run eagerly in Awake, and the difference only shows up as startup time in the Profiler. WithPattern logs when each resource is created instead.

## Where to begin

1. Read the pattern page: https://antoniucraciun.github.io/GameDevPatterns/patterns/lazy-initialization
2. Read [WithoutPattern](WithoutPattern/README.md) for why there is no "without" version.
