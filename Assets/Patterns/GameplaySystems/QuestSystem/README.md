# Quest System

**Category:** Gameplay Systems · **Site slug:** `quest-system`

> Quests as data: objectives, conditions and rewards driven by gameplay events.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Quest System, so you can run both and compare them.

The problem, from the page:

> The first quest is code: the wolf's death script checks `if (questManager.wolfQuestActive) wolfKills++`, and the item pickup checks for the herb quest. Every new quest adds checks to unrelated gameplay code.
