# Damage Pipeline

**Category:** Gameplay Systems · **Site slug:** `damage-pipeline`

> Run a damage event through ordered stages: mitigation, crits, shields, reactions.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Damage Pipeline, so you can run both and compare them.

The problem, from the page:

> Damage rules accumulate: critical hits, armour, fire resistance, a shield that absorbs damage first, an "immune to poison" buff, a curse that doubles damage taken, lifesteal, thorns, and "the first hit after stealth deals triple". Each rule is implemented where someone happened to need it, some in the weapon, some in `Health`, some in a buff.
