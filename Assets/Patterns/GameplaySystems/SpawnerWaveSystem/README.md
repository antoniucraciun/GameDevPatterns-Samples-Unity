# Spawner / Wave System

**Category:** Gameplay Systems · **Site slug:** `spawner`

> Data-driven waves and spawn points that control what appears, where and when.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Spawner / Wave System, so you can run both and compare them.

The problem, from the page:

> The first version of a horde mode is a coroutine: spawn 5 zombies, wait 10 seconds, spawn 8 zombies. Then design wants wave 7 to mix runners and tanks, the boss wave to wait until the arena is clear, spawns to never appear in the player's view, and the whole thing to be tunable without recompiling.
