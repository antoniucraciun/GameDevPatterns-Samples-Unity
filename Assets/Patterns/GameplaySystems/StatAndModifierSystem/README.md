# Stat & Modifier System

**Category:** Gameplay Systems · **Site slug:** `stat-modifier-system`

> Compute final stats from a base value plus ordered flat, additive and multiplicative modifiers.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Stat & Modifier System, so you can run both and compare them.

The problem, from the page:

> A character's damage comes from a base value, a sword (+15), a ring (+10%), a rage buff (+25%) and a curse (×0.5). The bonuses are added and removed at different times, by different systems.
