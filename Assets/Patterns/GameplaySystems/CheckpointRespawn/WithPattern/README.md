# Checkpoint / Respawn: with the pattern

The same feature built with Checkpoint / Respawn. The idea, from the page: **Checkpoints** record a restorable state at safe moments, and **respawn** restores it.

Compare it with [WithoutPattern](../WithoutPattern/README.md): the behaviour that broke there should hold here, at the cost of the extra types the pattern adds.
