# Checkpoint / Respawn

**Category:** Gameplay Systems · **Site slug:** `checkpoint`

> Record restorable state at safe points and rebuild the world on death.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Checkpoint / Respawn, so you can run both and compare them.

The problem, from the page:

> When the player dies, the simplest response is reloading the scene. But that also resets the doors they opened, the keys they picked up and the enemies they killed in the previous room.
