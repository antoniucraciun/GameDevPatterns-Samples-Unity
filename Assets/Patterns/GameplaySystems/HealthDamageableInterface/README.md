# Health / Damageable Interface

**Category:** Gameplay Systems · **Site slug:** `health-component`

> One interface lets anything take damage without the attacker knowing its type.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Health / Damageable Interface, so you can run both and compare them.

The problem, from the page:

> The sword script checks what it hit: `if (other is Enemy) ... else if (other is Player) ... else if (other is Crate)`. Every new destructible type means editing every weapon.
