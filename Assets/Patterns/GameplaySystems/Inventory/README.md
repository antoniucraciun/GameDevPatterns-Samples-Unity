# Inventory

**Category:** Gameplay Systems · **Site slug:** `inventory`

> Separate item definitions, item instances and containers with slots and stacking.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Inventory, so you can run both and compare them.

The problem, from the page:

> The first inventory is a list of scene objects. Then potions need to stack to 20, swords must not stack, a sword needs its own durability, the chest and the player's bag need to share logic, dragging an item onto a full stack should split the overflow, and the whole thing needs saving.
