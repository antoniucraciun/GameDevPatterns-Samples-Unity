# Ability System

**Category:** Gameplay Systems · **Site slug:** `ability-system`

> Data-driven abilities with costs, cooldowns, targeting and effects.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Ability System, so you can run both and compare them.

The problem, from the page:

> The first abilities are each a method: `CastFireball()`, `CastHeal()`, `Dash()`. Each one repeats the same checks (enough mana? off cooldown? not stunned? target in range?) slightly differently, and slightly wrong in different ways.
