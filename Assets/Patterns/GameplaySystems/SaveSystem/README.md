# Save System

**Category:** Gameplay Systems · **Site slug:** `save-system`

> Serialise game state through saveable components with versioned, migratable data.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Save System, so you can run both and compare them.

The problem, from the page:

> The first save code is one big method that reaches into the player, the inventory, every chest and every door, and writes their fields to a file. Each new feature means editing that method.
