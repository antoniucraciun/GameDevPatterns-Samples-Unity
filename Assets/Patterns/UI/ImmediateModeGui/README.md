# Immediate-Mode GUI

**Category:** UI · **Site slug:** `immediate-mode-gui`

> Describe the UI from scratch every frame instead of retaining widget objects.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Immediate-Mode GUI, so you can run both and compare them.

The problem, from the page:

> You need a quick debug panel: show the player's state, a few sliders for tuning, buttons to spawn enemies. With a retained-mode UI (uGUI or UI Toolkit, Godot's Control nodes, Unreal's UMG), that means creating a canvas, laying out widgets, wiring each button to a callback, and writing code to keep labels in sync with changing values.
