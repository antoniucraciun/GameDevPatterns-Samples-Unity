# Screen Stack

**Category:** UI · **Site slug:** `screen-stack`

> Manage menus and popups as a stack so Back always does the right thing.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Screen Stack, so you can run both and compare them.

The problem, from the page:

> The player opens Pause, then Settings, then Audio, then a "Discard changes?" confirmation. Pressing Back (Escape, B on a gamepad, or the Android back button) should close only the confirmation.
