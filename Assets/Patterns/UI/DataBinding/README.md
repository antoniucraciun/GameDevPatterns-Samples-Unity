# Data Binding

**Category:** UI · **Site slug:** `data-binding`

> UI elements update automatically from observable properties.

## What this sample will show

WithoutPattern builds a small feature the straightforward way and runs into the problem the page describes. WithPattern builds the same feature with Data Binding, so you can run both and compare them.

The problem, from the page:

> The HUD shows health, ammo, gold, level and a quest tracker. Every place that changes one of these values must also remember to update the right label: `gold += 10; goldLabel.text = gold.ToString();`.
