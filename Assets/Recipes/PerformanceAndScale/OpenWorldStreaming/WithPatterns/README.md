# Open-World Streaming: with patterns

The same feature built from Scene / Level Management, Asset References & Addressing, Level of Detail, Culling, Spatial Partition, Time Slicing, wired together as the [recipe page](https://antoniucraciun.github.io/GameDevPatterns/recipes/open-world-streaming) describes.

Compare it with [WithoutPatterns](../WithoutPatterns/README.md): the behaviour should match, and each pattern should replace a specific piece of the plain version.
