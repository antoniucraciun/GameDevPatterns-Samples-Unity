# Boss Fight: with patterns

The same feature built from Hierarchical State Machine, Behavior Tree, Feedback Layering (Juice), Checkpoint / Respawn, Health / Damageable Interface, Event Bus, wired together as the [recipe page](https://antoniucraciun.github.io/GameDevPatterns/recipes/boss-fight) describes.

Compare it with [WithoutPatterns](../WithoutPatterns/README.md): the behaviour should match, and each pattern should replace a specific piece of the plain version.
