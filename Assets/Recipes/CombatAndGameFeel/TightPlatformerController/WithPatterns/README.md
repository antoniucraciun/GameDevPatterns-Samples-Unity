# Tight Platformer Controller: with patterns

The same feature built from State, Input Buffer, Coyote Time, Fixed Timestep, wired together as the [recipe page](https://antoniucraciun.github.io/GameDevPatterns/recipes/platformer-controller) describes.

Compare it with [WithoutPatterns](../WithoutPatterns/README.md): the behaviour should match, and each pattern should replace a specific piece of the plain version.
