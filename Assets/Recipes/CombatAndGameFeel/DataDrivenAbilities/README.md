# Data-Driven Abilities

**Group:** Combat & Game Feel · **Site slug:** `data-driven-abilities`

> Designers create new abilities as assets: costs, cooldowns, effects and buffs without code.

## What this sample will show

WithoutPatterns builds this feature directly, with plain scripts and no patterns, the way you would build it first. WithPatterns builds the same feature with the five patterns below working together, as the recipe page describes, so you can see where the plain version strains and what each pattern takes over.
