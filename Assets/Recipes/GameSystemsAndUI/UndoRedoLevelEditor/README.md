# Undo/Redo Level Editor

**Group:** Game Systems & UI · **Site slug:** `undo-redo-editor`

> Every edit is undoable and redoable, including grouped edits, with the UI always in sync.

## What this sample will show

WithoutPatterns builds this feature directly, with plain scripts and no patterns, the way you would build it first. WithPatterns builds the same feature with the three patterns below working together, as the recipe page describes, so you can see where the plain version strains and what each pattern takes over.
