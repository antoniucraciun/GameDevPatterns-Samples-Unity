# Save & Load: with patterns

The same feature built from Save System, Memento, Inventory, Data-Driven Design, Scene / Level Management, wired together as the [recipe page](https://antoniucraciun.github.io/GameDevPatterns/recipes/save-and-load) describes.

Compare it with [WithoutPatterns](../WithoutPatterns/README.md): the behaviour should match, and each pattern should replace a specific piece of the plain version.
