# RPG Character Sheet

**Group:** Game Systems & UI · **Site slug:** `rpg-character-sheet`

> Stats from gear, buffs and talents that update the UI only when something changes.

## What this sample will show

WithoutPatterns builds this feature directly, with plain scripts and no patterns, the way you would build it first. WithPatterns builds the same feature with the four patterns below working together, as the recipe page describes, so you can see where the plain version strains and what each pattern takes over.
