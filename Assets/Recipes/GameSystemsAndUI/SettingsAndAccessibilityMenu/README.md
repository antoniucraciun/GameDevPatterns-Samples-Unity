# Settings & Accessibility Menu

**Group:** Game Systems & UI · **Site slug:** `settings-menu`

> Audio, language, controls and accessibility options that apply live, persist safely and can be reverted.

## What this sample will show

WithoutPatterns builds this feature directly, with plain scripts and no patterns, the way you would build it first. WithPatterns builds the same feature with the six patterns below working together, as the recipe page describes, so you can see where the plain version strains and what each pattern takes over.
