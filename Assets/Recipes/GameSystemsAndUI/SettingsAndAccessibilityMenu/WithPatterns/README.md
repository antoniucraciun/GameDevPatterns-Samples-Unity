# Settings & Accessibility Menu: with patterns

The same feature built from Screen Stack, Data Binding, Input Abstraction, Save System, Localization Tables, Feature Flags, wired together as the [recipe page](https://antoniucraciun.github.io/GameDevPatterns/recipes/settings-menu) describes.

Compare it with [WithoutPatterns](../WithoutPatterns/README.md): the behaviour should match, and each pattern should replace a specific piece of the plain version.
