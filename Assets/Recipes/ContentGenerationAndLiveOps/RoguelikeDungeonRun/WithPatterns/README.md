# Roguelike Dungeon Run: with patterns

The same feature built from BSP Dungeon Generation, Cellular Automata, Seeded Randomness, Navigation Mesh, Spawner / Wave System, Weighted Random & Loot Tables, wired together as the [recipe page](https://antoniucraciun.github.io/GameDevPatterns/recipes/roguelike-dungeon-run) describes.

Compare it with [WithoutPatterns](../WithoutPatterns/README.md): the behaviour should match, and each pattern should replace a specific piece of the plain version.
