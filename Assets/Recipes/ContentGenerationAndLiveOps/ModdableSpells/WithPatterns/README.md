# Moddable Spells: with patterns

The same feature built from Bytecode, Interpreter, Ability System, Data-Driven Design, Asset References & Addressing, wired together as the [recipe page](https://antoniucraciun.github.io/GameDevPatterns/recipes/moddable-spells) describes.

Compare it with [WithoutPatterns](../WithoutPatterns/README.md): the behaviour should match, and each pattern should replace a specific piece of the plain version.
