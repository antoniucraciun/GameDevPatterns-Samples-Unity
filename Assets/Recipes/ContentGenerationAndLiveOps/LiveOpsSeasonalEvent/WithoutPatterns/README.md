# Live-Ops Seasonal Event: without patterns

The feature built directly, with plain MonoBehaviours, direct references and no patterns. This is the version the [Keep It Simple](https://antoniucraciun.github.io/GameDevPatterns/keep-it-simple) page says to build first, so it should work and stay readable at small scale.

Compare it with [WithPatterns](../WithPatterns/README.md): count the places you would have to edit to add one more case, and look for the bugs the recipe page warns about.

Status: not implemented yet.
